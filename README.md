## 👋 About me

I build small security tools, mostly in pure Python (standard library only) — clone and
run, nothing to install. I care about code that's clean and easy to audit, and I'd rather
have ten tools that each do one job than one that tries to do everything. Offense to find
the problem, defense to shut it. 🥷

Currently on Kali, hunting bugs on the side and writing the tooling I wish existed.
