## 🔧 Featured Tools

> Built for **authorized security testing and education only.**

| Project | What it does |
|---|---|
| ⚡ [**portsweep**](https://github.com/Zaphh-Tech/portsweep) | Fast async TCP port scanner — service names + banner grabbing, no nmap, no root |
| 🔎 [**paramhunt**](https://github.com/Zaphh-Tech/paramhunt) | Finds a page's parameters from links, forms & JS, and exports an ffuf wordlist |
| 🛡️ [**headercheck**](https://github.com/Zaphh-Tech/headercheck) | Grades any site's HTTP security headers A–F (CSP, HSTS, CORS misconfig) |
| 📡 [**subwatch**](https://github.com/Zaphh-Tech/subwatch) | Tracks a target's subdomains over time and alerts when a new one appears |
| 🚨 [**logtail-alert**](https://github.com/Zaphh-Tech/logtail-alert) | Detects SSH brute-force in auth logs with a sliding window + live follow mode |
| 🕸️ [**arpwatch-lite**](https://github.com/Zaphh-Tech/arpwatch-lite) | Passive LAN monitor — learns your devices, flags new ones and ARP spoofing |
| 🌐 [**egress-toolkit**](https://github.com/Zaphh-Tech/egress-toolkit) | Per-identity egress routing (Firefox extension) + proxy-fleet health CLI |
